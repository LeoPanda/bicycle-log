# 本番環境アクセス障害（画面非表示）原因調査および復旧レポート

**障害発生日**: 2026-08-30
**対象システム**: 自転車走行・滞在記録システム (`bicycle-log`)
**本番 URL**: `https://bicycle-log-949662653974.asia-northeast1.run.app`
**復旧ステータス**: **完全復旧済 (RESLOVED)**

---

## 1. 障害事象
本番環境 URL (`https://bicycle-log-949662653974.asia-northeast1.run.app`) にブラウザでアクセスした際、画面が白くなり（White Screen of Death）、React SPA アプリケーションが描画・表示されない現象が発生していました。

---

## 2. 根本原因の解析 (Root Cause Analysis)

### 原因: FastAPI における静的アセットルーティングの未マウントおよび全件 HTML フォールバック

1. **Vite SPA ビルド構造**:
   React SPA のビルド成果物は `dist/assets/index-XXXX.js` および `dist/assets/index-XXXX.css` を生成し、`index.html` 内で `/assets/...` パスとして参照します。
2. **FastAPI ルーティングの不備**:
   `backend/app/main.py` の従来の配信ルーティングにおいて、静的アセットディレクトリ `/static` のみがマウントされており、`/assets` に対する `StaticFiles` マウントが存在しませんでした。
3. **MIME タイプの不一致による JS 実行拒否**:
   ブラウザが `<script type="module" src="/assets/index-XXXX.js">` を読み込もうとした際、FastAPI の SPA フォールバック `@app.get("/{full_path:path}")` が動作し、JS ファイルではなく **`index.html` (text/html)** を返却しました。
   これにより、ブラウザ側で **`Uncaught SyntaxError: Unexpected token '<'`** が発生し、JavaScript の実行が即座に停止されたため画面が白いままになりました。

---

## 3. 実施した修復対応 (Remediation)

1. **`backend/app/main.py` の修正**:
   - `/assets` ディレクトリを StaticFiles として明示的にマウント処理を追加：
     `app.mount("/assets", StaticFiles(directory=assets_dir), name="assets")`
   - `serve_spa` ハンドラにて、リクエストされたパスに実在する静的ファイルが存在する場合は `FileResponse(target_file)` により適切な Content-Type（`application/javascript`, `text/css` 等）で即時返却するようルーティングを最適化。
2. **`frontend/src/pages/DashboardPage.tsx` の安全性向上**:
   - `summary?.total_distance_km` / `summary?.total_elevation_gain_m` の評価ロジックに Optional Chaining とデフォルト値 `(summary?.total_distance_km ?? 0).toLocaleString()` を適用し、データ非同期取得時の TypeError 例外スローを防止。
3. **ビルドおよび再デプロイ**:
   - フロントエンドの再ビルド (`npm run build`)
   - `linux/amd64` 統合 Docker イメージの構築・プッシュ
   - Cloud Run への最新リビジョン (`bicycle-log-00004-jkh`) のデプロイ
