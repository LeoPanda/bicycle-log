# 本番環境のデータベースをクリーンアップし、ローカルデータベースから再構築する手順

1. 旧コンテナの完全停止: 本番環境のサービスを一時的にトラフィック遮断、またはインスタンス数を 0 にスケールダウンし、旧 Litestream プロセスからの書き込みを完全に防ぎます。
2. GCS バックアップバケットのクリーンアップ: 旧コンテナ停止を確認した上で、GCS バケット (gs://[BUCKET_NAME]/db/) 内の全オブジェクトを削除します。
3. ローカル DB を含めた新統合イメージのビルド & デプロイ: ローカルの data/app.db を含むイメージを Cloud Build でビルドし、Cloud Run へデプロイします。
4. 初回シード & 新世代レプリケーションの開始: GCS バケットが空のため、litestream restore はスキップされ、data-backup/app.db から新 DB が正常に初期ロードされ、新たな Generation として GCS への同期が開始されます。
