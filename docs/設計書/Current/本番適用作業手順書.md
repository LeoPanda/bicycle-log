# 本番適用作業手順書 (PRODUCTION DEPLOYMENT GUIDE)

## 1. 概要と単一統合コンテナアーキテクチャ

本ドキュメントは、「自転車走行・滞在記録システム (bicycle-log)」を Google Cloud 上の本番環境 (Cloud Run) へ移行・適用するための標準手順書である。

- **対応要件**: `[REQ-NF02]`, `[REQ-NF05]`, `[REQ-NF06]`, `[REQ-NF07]`
- **採用プロファイル**: Profile A (サーバーレス極小コストWeb型: Cloud Run + Litestream + SQLite WAL + Alembic + React SPA + Tailwind CSS)

```
 [ インターネット (PC / スマホ) ]
        │ (HTTPS / GCP Cloud Run IAP (Identity-Aware Proxy) 認証) [REQ-NF05]
        ▼
   [ Cloud Run (単一統合コンテナ) ]     <-- 最小インスタンス=0 / 最大インスタンス=1 (書き込み競合防止)
   │  - FastAPI (8000ポート / REST API + 静的SPA配信 `/app/static`) [REQ-NF01]
   │  - React SPA (フロントエンド静的ビルド成果物 / VITE_ENABLE_MOCK=false) [REQ-NF07]
   │  - Litestream (バックグラウンドレプリケーションプロセス)
   │    │                                     │
   │    │ (WAL 変更ログ非同期同期)            │ (画像一元管理・アップロード/参照) [REQ-F04]
   │    ▼                                     ▼
 [ Cloud Storage (Litestream用GCS) ]    [ Cloud Storage (画像用GCS) ]
   (gs://[PROJECT_ID]-bicycle-log-litestream-backend)
```

## 3. 本番デプロイおよび Alembic マイグレーション実行手順

```bash
# 1. 依存関係 & マイグレーションチェック
alembic upgrade head

# 2. 本番用統合Dockerイメージのビルド & プッシュ
docker build -f Dockerfile.prod -t asia-northeast1.pkg.dev/[PROJECT_ID]/bicycle-log-repo/app:latest .
docker push asia-northeast1.pkg.dev/[PROJECT_ID]/bicycle-log-repo/app:latest

# 3. Cloud Run デプロイ (max-instances=1 固定)
gcloud run deploy bicycle-log \
    --image=asia-northeast1.pkg.dev/[PROJECT_ID]/bicycle-log-repo/app:latest \
    --region=asia-northeast1 \
    --platform=managed \
    --allow-unauthenticated \
    --max-instances=1 \
    --min-instances=0 \
    --set-env-vars=APP_VERSION=2.0.0,DATABASE_URL=sqlite:////app/data/app.db,TZ=Asia/Tokyo,LOG_LEVEL=INFO,GCS_BUCKET_NAME_IMAGES=[PROJECT_ID]-bicycle-log-images,GCS_LITESTREAM_BACKUP_BUCKET=[PROJECT_ID]-bicycle-log-litestream-backend \
    --set-secrets=INTERNAL_AI_TOKEN=INTERNAL_AI_TOKEN:latest,STRAVA_CLIENT_ID=STRAVA_CLIENT_ID:latest,STRAVA_CLIENT_SECRET=STRAVA_CLIENT_SECRET:latest,STRAVA_REFRESH_TOKEN=STRAVA_REFRESH_TOKEN:latest,GOOGLE_PLACES_API_KEY=GOOGLE_PLACES_API_KEY:latest
```
